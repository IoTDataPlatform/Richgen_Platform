# Iot Data Platform - Richgen demo project

Демо-кейс, показывающий сценарий работы IoT-платформы для детектирования частиц (Rich / Ring-imaging Cherenkov detector): в каждый момент времени приходит поток hit-ов (срабатываний пикселей/каналов детектора), и задача — выделить частицы на фоне шума.
